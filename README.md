# آرک‌فایل | طراحی رابط کاربری فروشگاه فایل‌های معماری

طرح رابط کاربری صفحه اصلی یک فروشگاه آنلاین برای فروش فایل‌های دیجیتال معماری، شامل خروجی پروژه‌های Revit، 3ds Max، AutoCAD، SketchUp، تکسچرها و مدل‌های سه‌بعدی. این طرح با هوش مصنوعی Google Stitch ساخته و به‌صورت دستی بهینه شده است.

## ویژگی‌ها

- طراحی کاملاً راست‌چین (RTL) و فارسی
- استفاده از فونت وزیرمتن (Vazirmatn) در تمام بخش‌ها
- تم روشن و گرم با رنگ تاکیدی ترکوتایی
- طراحی عکس‌محور و مینیمال با فضای خالی زیاد
- ریسپانسیو برای دسکتاپ و موبایل
- ساخته‌شده با HTML و Tailwind CSS

## بخش‌های صفحه

1. هدر ساده و تمیز
2. هیرو با رندر معماری و کارت شناور فایل
3. نوار نرم‌افزارهای پشتیبانی‌شده
4. دسته‌بندی‌ها (ویلا، اینتریور، نما، تکسچر)
5. فایل‌های منتخب
6. مراحل خرید (انتخاب، پرداخت، دانلود)
7. بنر دعوت به عمل و فوتر
